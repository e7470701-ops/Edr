# EDR — David Ernest Restaurants

Plateforme de démonstration gratuite pour présenter des vitrines numériques de restaurants.

## Démonstration actuelle
- Accueil : `/`
- Restaurant de démonstration : `/restaurants/demo-restaurant/`
- Modèle restaurant Essentiel : `/restaurants/demo-essentiel/`
- Modèle restaurant Pro : `/restaurants/demo-pro/`
- Les deux nouveaux modèles reprennent la même carte fictive pour permettre une comparaison directe des formules.
- Chaque page restaurant génère un QR code à partir de son adresse courante.
- Le contenu du restaurant est fictif : remplacer le nom, les photos, le menu, les prix, les coordonnées et les horaires avant livraison client.

## Fonctionnement visé
Une plateforme commune avec un chemin public distinct par entreprise, par exemple `/restaurants/nom-du-restaurant/`. Au départ, la personnalisation et la publication sont manuelles. Aucun système de paiement, d'espace client autonome ou de gestion d'abonnements n'est déclaré opérationnel dans cette version.

## Publication
Le dépôt est prévu pour Cloudflare Pages, branche `main`, sans commande de build et sans frais payants requis. Les images et le service de génération de QR code sont chargés depuis des services externes gratuits et nécessitent une connexion internet.

## Tarifs des vitrines David Ernest
- Essentiel : création 7 500 FCFA + abonnement obligatoire de 2 000 FCFA/mois.
- Business personnalisé : création 15 000 FCFA + abonnement obligatoire de 3 500 FCFA/mois.

Les modifications et améliorations après livraison sont facturées séparément, après définition du besoin, des livrables et accord sur le prix.

Dernière configuration : connexion Cloudflare Pages au dépôt EDR sur la branche main.
